# macOS 高效开发快捷键指南

## 🚀 系统核心操作

| 快捷键 | 功能说明 |
|:---|:---|
| **Command + Space** | Spotlight 搜索（快速启动应用/搜文件） |
| **Command + Tab** | 应用间切换 |
| **Command + \`** | 同应用不同窗口间切换（如多个 VS Code 实例） |
| **Command + Option + Esc** | 强制退出应用程序 |
| **Control + Command + Q** | 立即锁屏 |
| **Shift + Command + 5** | 截图与录屏管理工具 |

## 📂 访达 (Finder) 与路径管理

| 快捷键 | 功能说明 |
|:---|:---|
| **Command + N** | 新建 Finder 窗口 |
| **Shift + Command + G** | 前往文件夹（支持绝对路径输入） |
| **Option + Command + C** | 拷贝当前选中项目的 **文件路径** |
| **Command + Shift + .** | 切换显示/隐藏文件（. 开头文件） |
| **Command + I** | 显示项目简介（权限、大小、路径） |
| **Command + Down (↓)** | 打开选中的文件夹或文件 |

## 📝 文本编辑与开发通用

* **Command + ← / →**：跳转至行首 / 行尾
* **Option + ← / →**：按单词跳转光标
* **Command + ↑ / ↓**：跳转至文档首 / 尾
* **Control + A / E**：Unix 风格跳转行首 / 行尾
* **Control + K**：删除光标处至行尾的所有内容
* **Command + Z / Shift + Command + Z**：撤销 / 重做

## 🌐 浏览器 (Chrome/Edge/Safari)

| 快捷键 | 功能说明 |
|:---|:---|
| **Command + L** | 聚焦到地址栏 |
| **Command + T / N** | 新建标签页 / 新建窗口 |
| **Command + Option + I** | 打开开发者工具 (Inspect) |
| **Shift + Command + T** | 重新打开最近关闭的标签页 |
| **Command + 1 \~ 9** | 切换到对应序号的标签页 |
