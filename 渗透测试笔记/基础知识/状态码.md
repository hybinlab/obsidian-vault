# 状态码

**信息性响应（100-199）**\n这些代码表示服务器已收到部分请求，正在等待剩余部分__。__这是一个"继续处理"的信号。

**成功响应（200-299）**\n：这些代码表示一切运行正常。服务器已处理请求并返回了请求的数据。

**重定向消息（300-399）**\n这些代码告诉您，您请求的资源已移动到不同的位置，通常会提供新的 URL。

**客户端错误响应（400-499）**\n：这些代码表示请求存在问题。可能是 URL 错误，或者缺少某些必需信息，例如身份验证信息。

**服务器错误响应（500-599）**


以下是一些最常见的状态代码：

**100（继续）**\n服务器已收到请求的第一部分，并准备好接收其余__部分__。

**200 (OK)**\n请求成功，服务器正在发送请求的资源。

**301（永久重定向）**\n您请求的资源已永久迁移到新的 URL。请从现在开始使用新的 URL。

**404（未找到）**\n服务器无法在给定的 URL 处找到资源。请仔细检查您输入的地址是否正确。

**500（内部服务器错误）**\n服务器端出现问题，无法处理您的请求。
