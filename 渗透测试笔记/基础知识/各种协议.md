## DNS

__DNS__运行于应用层，即 ISO OSI 模型中的第七层。DNS__通信__默认使用__UDP端口 53，默认备用端口为TCP端口 53。__

想从命令行查找某个域名的 IP 地址，可以使用类似`nslookup`. 这样的工具。请看下面的终端示例，在这里查找`example.com`.

```bash
user@TryHackMe$ nslookup www.example.com
Server:         127.0.0.53
Address:        127.0.0.53#53

Non-authoritative answer:
Name:   www.example.com
Address: 93.184.215.14
Name:   www.example.com
Address: 2606:2800:21f:cb07:6820:80da:af6b:8b2c
```

* **A 记录**：A（地址）记录将主机名映射到一个或多个 IPv4 地址。例如，您可以将其设置`example.com`为解析到`172.17.2.172`。
* **AAAA 记录**：AAAA 记录类似于 A 记录，但它是用于 IPv6 的。请记住它是 AAAA（四 A），因为 AA 和 AAA 指的是电池容量；此外，AAA 指的是*身份验证、授权和计费*；这两者都不属于__DNS 的__范畴。
* **CNAME 记录**：CNAME（规范名称）记录将一个域名映射到另一个域名。例如，`www.example.com`可以将一个域名映射到另一个域名`example.com`，甚至可以映射到另一个域名`example.org`。
* **MX 记录**：MX（邮件交换）记录指定负责处理域的电子邮件的邮件服务器。

换句话说，当`example.com`在浏览器中输入域名时，浏览器会尝试通过向 DNS 服务器查询 A 记录来解析该域名。但是，当你尝试向该域名发送电子邮件时`test@example.com`，邮件服务器会向__DNS__服务器查询 MX 记录。
