# GPG/PGP 加密

## 基本概念

* **PGP (Pretty Good Privacy)**: 用于文件加密、数字签名等功能的加密软件
* **GPG (GnuPG)**: OpenPGP 标准的开源实现
* **主要用途**:
  * 保护电子邮件机密性
  * 对邮件进行数字签名以确认完整性
  * 文件加密与解密

## 生成 GPG 密钥

### 生成命令

```bash
gpg --full-gen-key
```

### 配置选项


1. **密钥类型选择**:
   * RSA and RSA
   * DSA and Elgamal
   * ECC (椭圆曲线加密) - 推荐
   * 等多种选项
2. **椭圆曲线选择** (如选择 ECC):
   * Curve 25519 (默认推荐)
   * NIST P-384
   * Brainpool P-256
3. **有效期设置**:
   * 0 = 永不过期
   * n days/weeks/months/years = 指定时间后过期
4. **用户信息**:
   * 真实姓名
   * 电子邮件地址
   * 备注(通常说明密钥用途)

## 密钥保护与破解

* 私钥可以用密码短语(passphrase)保护,类似 SSH 私钥
* **破解受密码保护的密钥**:
  * 使用 John the Ripper 工具
  * 配合 `gpg2john` 命令

## 实际应用

### 密钥分享与使用流程


1. **分享公钥**: 将公钥分发给联系人
2. **接收加密消息**: 对方使用你的公钥加密消息
3. **解密消息**: 使用你的私钥解密

### 密钥备份与恢复

**重要**: 务必在安全位置备份密钥副本

**导入备份密钥**:

```bash
gpg --import backup.key
```

**解密消息**:

```bash
gpg --decrypt confidential_message.gpg
```
