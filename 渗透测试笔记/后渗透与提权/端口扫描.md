## UDP服务标识

`scanner/discovery/udp_sweep` 模块可帮助您快速识别运行在__UDP__（用户数据报协议）上的服务。如下所示，该模块不会对所有可能的__UDP__服务进行全面扫描，但可以快速识别诸如__DNS__或 __NetBIOS__之类的服务。

## **__SMB__扫描**

在企业网络中特别有用的模块是 `smb_enumshares` 和 `smb_version`

```python
msf6 auxiliary(scanner/smb/smb_version) > run

[+] 10.10.12.229:445      - Host is running Windows 7 Professional SP1 (build:7601) (name:JON-PC) (workgroup:WORKGROUP ) (signatures:optional)
[*] 10.10.12.229:445      - Scanned 1 of 1 hosts (100% complete)
[*] Auxiliary module execution completed
msf6 auxiliary(scanner/smb/smb_version) >
```

在执行服务扫描时，重要的是不要忽略更"特殊"的服务，例如 NetBIOS。NetBIOS（网络基本输入输出系统）与 SMB 类似，允许计算机通过网络进行通信以共享文件或将文件发送到打印机。目标系统的 NetBIOS 名称可以让您了解其角色甚至重要性（例如 CORP-DC、DEVOPS、SALES 等）。可能还会遇到一些可以无需密码或受简单密码（例如 admin、administrator、root、toor 等）保护的共享文件和文件夹。

### 工作流程示例


1. 我们将使用漏洞扫描模块，通过`use auxiliary/scanner/smb/smb_ms17_010`命令查找潜在的 MS17-010 漏洞。
2. 我们使用 . 设置 RHOSTS 值`hosts -R`。
3. 我们输入命令是 `show options`为了检查所有值是否都已正确赋值。（在本例中，10.10.138.32 是我们之前使用命令扫描到的 IP 地址`db_nmap`。）
4. 所有参数设置完毕后，我们使用`run` or`exploit` 命令启动漏洞利用程序。 

```bash
msf6 > use auxiliary/scanner/smb/smb_ms17_010
```

在典型的渗透测试项目中，我们可能会遇到以下情况： 

* `db_nmap` 使用命令查找可用主机
* 扫描这些端口是否存在其他漏洞或开放端口（使用端口扫描模块）

可以先寻找一些容易实现的目标，例如：

* __HTTP__：可能托管 Web 应用程序，其中可能存在__SQL__注入或远程代码执行 ( __RCE__ ) 等漏洞。
* __FTP__：可以允许匿名登录并提供对有趣文件的访问权限。
* __SMB__：可能容易受到MS17-010 等__SMB漏洞攻击。__
* __SSH__：可能使用默认凭据或容易猜测的凭据。
* __RDP__：可能容易受到 Bluekeep 攻击，或者如果使用弱凭据，则可能允许桌面访问。

### **sessions 命令常用参数表格**

| **参数** | **功能描述** | **示例** |
|----|----|----|
| `-l` | 列出所有活动会话 | `sessions -l` |
| `-i <id>` | 与指定会话ID交互 | `sessions -i 1` |
| `-v` | 详细模式列出所有活动会话 | `sessions -v` |
| `-d` | 列出所有非活动会话 | `sessions -d` |
| `-K` | 终止所有会话 | `sessions -K` |
| `-k <id>` | 终止指定会话ID | `sessions -k 1,3-5` |
| `-c <命令>` | 在会话上运行命令 | `sessions -c "whoami" -i 1` |
| `-C <Meterpreter命令>` | 运行Meterpreter命令 | `sessions -C "getuid" -i 1` |
| `-s <脚本>` | 在会话上运行脚本或模块 | `sessions -s post/multi/gather/env -i 1` |
| `-u` | 将shell升级为Meterpreter会话 | `sessions -u 1` |
| `-n <名称>` | 为会话命名或重命名 | `sessions -n "DC-Server" -i 1` |
| `-q` | 静默模式 | `sessions -q` |
| `-t <秒>` | 设置响应超时时间（默认15秒） | `sessions -t 30 -i 1` |
| `-S <过滤器>` | 行搜索过滤 | `sessions -S "windows"` |
| `-x` | 在会话表中显示扩展信息 | `sessions -x` |
| `-h` | 显示帮助信息 | `sessions -h` |
