# wget

`wget:`该命令允许通过 HTTP 从网络下载文件——就像在浏览器中访问文件一样。只需要提供要下载的资源的地址即可。例如，如果我想将名为"myfile.txt"的文件下载到我的电脑上，假设我知道它的网址——命令看起来会像这样：

# scp

Secure copy (SCP),与普通的cp命令不同，SCP命令允许使用SSH协议在两台计算机之间传输文件，从而提供身份验证和加密。

基于源和目标模型，SCP 允许我们：

* 将当前系统中的文件和目录复制到远程系统
* 将远程系统中的文件和目录复制到当前系统

前提是我们知道当前系统上一个用户和远程系统上一个用户的用户名和密码。例如，让我们将一个示例文件从我们的机器复制到远程机器，我已在下表中清晰地列出了相关信息：

```bash
scp important.txt ubuntu@192.168.1.30:/home/ubuntu/transferred.txt
```


# **__进程是如何启动的？__**

我们先来谈谈命名空间。操作系统 (OS) 使用命名空间来划分计算机上的可用资源（例如 CPU、内存和优先级），供各个进程使用。你可以把它想象成把计算机切成若干块——就像切蛋糕一样。每块"切片"内的进程都可以访问一定量的计算能力，但这仅仅是所有进程可用资源的一小部分。

命名空间对于安全性来说非常有用，因为它是一种将进程与其他进程隔离的方法——只有位于同一命名空间中的进程才能相互看到。

我们之前讨论过进程__ID (PID)__的工作原理，而这正是它发挥作用的地方。ID 为 0 的进程是在系统启动时启动的进程。在 Ubuntu 系统中，这个进程是系统的初始化程序，例如**systemd**，它用于管理用户进程，并位于操作系统和用户之间。 

例如，系统启动并初始化后，**systemd**是最先启动的进程之一。任何我们想要启动的程序或软件都会作为**systemd**的子进程启动。这意味着它由**systemd控制，但会作为独立的进程运行（尽管共享systemd**的资源），以便我们更容易识别它等等。

# crontab

希望在系统启动后安排某些操作或任务.

crontab 是一种特殊的程序文件，其格式能够被进程识别`cron`，并按步骤执行其中的每一行。crontab 需要 6 个特定的值：

| 值 | 描述 |
|----|----|
| MIN | 在哪一分钟执行 |
| HOUR | 在哪一小时执行 |
| DOM | 在每月的哪一天执行 |
| MON | 在一年中的哪个月执行 |
| DOW | 在一周中的哪一天执行 |
| CMD | 将要执行的实际命令 |


我们以备份文件为例。您可能希望每 12 小时备份一次"cmnatic"的"文档"文件夹。我们将使用以下格式： 

`0 */12 * * * cp -R /home/cmnatic/Documents /var/backups/`

crontab 的一个有趣特性是它支持通配符或星号 (\* `*`)。如果我们不想为某个特定字段提供值，例如，我们不在乎它在哪年哪月哪日执行，只关心它每 12 小时执行一次，我们只需输入一个星号即可。
