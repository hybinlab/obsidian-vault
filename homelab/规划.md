## 堡垒机（LXC）

| 服务 | 用途 | 链接 |
|----|----|----|
| frp client | 内网穿透，连接公网 frp server | [GitHub](https://github.com/fatedier/frp) |
| Nginx | 内网反代，按子域名路由到各服务 | [nginx.org](https://nginx.org) |
| JumpServer | 堡垒机，资产管理 + 会话审计 + 权限控制，复用基础设施层 MySQL + Redis | [jumpserver.org](https://www.jumpserver.org) |

### 子域名规划（示例）

| 子域名 | 指向服务 |
|----|----|
| `js.domain.com` | JumpServer |
| `outline.domain.com` | Outline |
| `jellyfin.domain.com` | Jellyfin |
| `music.domain.com` | Navidrome |
| `books.domain.com` | Kavita |
| `calibre.domain.com` | Calibre |
| `rss.domain.com` | FreshRSS |
| `pan.domain.com` | OpenList |
| `ha.domain.com` | Home Assistant |
| `monitor.domain.com` | Grafana |

> 公网服务器 Nginx 负责 TLS 终结（Let's Encrypt），堡垒机 Nginx 做最后一跳内网路由。未列出的服务仅内网访问。

## 说明

* IPTV 通过 Jellyfin Live TV 内置功能接 m3u 源，无需单独部署服务
* Calibre 使用 `linuxserver/calibre` 镜像，通过 KasmVNC 提供 Web 图形界面
* Prometheus 监控范围：PVE 宿主机、所有常驻 VM/LXC、MySQL、PostgreSQL
* JumpServer 依赖复用基础设施层的 MySQL 和 Redis，不在堡垒机本地单独部署
