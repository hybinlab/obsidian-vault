# 内网网关部署文档

> 目标：LXC 103 运行 Nginx 作为反向代理，OpenWRT 提供内网 DNS 解析，实现 `*.home` 域名访问内网服务。


---

## 环境信息

| 组件 | IP | 说明 |
|----|----|----|
| LXC 103 (堡垒机) | 192.168.31.103 | Nginx 所在容器 |
| PVE 宿主机 | 192.168.31.2 | 管理界面 8006 |
| Docker-Host (LXC 101) | 192.168.31.4 | 各应用所在容器 |
| OpenWRT | 192.168.31.1 | 路由器/DNS |


---

## 一、安装 Nginx

登录 LXC 103：

```bash
apt update && apt install nginx -y
systemctl enable nginx
systemctl start nginx
```

验证安装：

```bash
nginx -v
systemctl status nginx
```

删除默认配置：

```bash
rm /etc/nginx/sites-enabled/default
```


---

## 二、配置 Nginx 反向代理

每个服务单独一个配置文件，统一放在 `/etc/nginx/sites-available/`。

### PVE 管理界面

```bash
nano /etc/nginx/sites-available/pve.home.conf
```

```nginx
server {
    listen 80;
    server_name pve.home;

    location / {
        proxy_pass https://192.168.31.2:8006;
        proxy_ssl_verify off;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### code-server

```bash
nano /etc/nginx/sites-available/code.home.conf
```

```nginx
server {
    listen 80;
    server_name code.home;

    location / {
        proxy_pass http://192.168.31.4:8888;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 毕设前端 (web)

```bash
nano /etc/nginx/sites-available/web.home.conf
```

```nginx
server {
    listen 80;
    server_name web.home;

    location / {
        proxy_pass http://192.168.31.4:2208;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 毕设后端 (api)

```bash
nano /etc/nginx/sites-available/api.home.conf
```

```nginx
server {
    listen 80;
    server_name api.home;

    location / {
        proxy_pass http://192.168.31.4:8001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### Openlist

```bash
nano /etc/nginx/sites-available/openlist.home.conf
```

```nginx
server {
    listen 80;
    server_name openlist.home;

    location / {
        proxy_pass http://192.168.31.4:5244;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 启用所有配置

```bash
ln -s /etc/nginx/sites-available/*.conf /etc/nginx/sites-enabled/

# 检查语法
nginx -t

# 重载
systemctl reload nginx
```

## 三、OpenWRT 配置 DNS

登录 LuCI 界面 → **网络** → **DHCP/DNS** → **自定义 DNS 记录**

逐条添加以下记录（格式为 `/域名/IP`）：

```
/pve.home/192.168.31.103
/code.home/192.168.31.103
/web.home/192.168.31.103
/api.home/192.168.31.103
/openlist.home/192.168.31.103
```

点击**保存并应用**。

> 所有域名均指向 LXC 103，由 Nginx 负责转发到对应服务。

## 四、验证

### 1. 验证 DNS 解析

在局域网内任意设备执行：

```bash
ping pve.home
```

预期结果：解析到 `192.168.31.103`。

### 2. 验证 Nginx 转发

```bash
curl -I http://pve.home
curl -I http://openlist.home
```

预期结果：返回 `HTTP/1.1 200 OK` 或 `301/302` 跳转（PVE 会跳转到 HTTPS）。

### 3. 浏览器访问

| 地址 | 对应服务 |
|----|----|
| http://pve.home | PVE 管理界面 |
| http://code.home | code-server |
| http://web.home | 毕设前端 |
| http://api.home | 毕设后端 |
| http://openlist.home | Openlist |

## 五、后续新增服务

新增服务只需两步：


1. 在 LXC 103 新建 `/etc/nginx/sites-available/xxx.home.conf`，参照上方模板填写
2. 在 OpenWRT DNS 记录中添加 `/xxx.home/192.168.31.103`

```bash
# 启用新配置
ln -s /etc/nginx/sites-available/xxx.home.conf /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
```

