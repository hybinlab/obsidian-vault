## 最常用的快捷键

| 按键 | 作用 |
| --- | --- |
| `Esc` | 打断 Claude 当前的回复或工具调用，已完成的工作保留，可以马上纠正方向 |
| `Esc` `Esc` | 输入框有字：清空（存进历史，`↑` 可找回）；输入框为空：打开 **rewind 菜单**回滚 |
| `Shift+Tab` | 循环切换权限模式：Manual → acceptEdits → plan →（auto） |
| `Ctrl+C` | 中断；空闲时第一次清空输入，第二次退出 |
| `Ctrl+D` | 退出（800ms 内按两次） |
| `Ctrl+G` | 用外部编辑器编辑当前提示词（plan mode 下也能直接编辑计划） |
| `Ctrl+O` | 打开完整记录视图，看工具调用细节 |
| `Ctrl+R` | 反向搜索历史提示词 |
| `Ctrl+B` | 把正在跑的 Bash 命令/子代理放到后台（**tmux 里要按两次**） |
| `Ctrl+T` | 显示/隐藏 Claude 的任务清单 |
| `Ctrl+S` | 暂存当前输入；空输入时再按一次恢复 |
| `Ctrl+V` | 粘贴剪贴板图片 |
| `Ctrl+L` | 重绘屏幕（显示乱了时用） |
| `Ctrl+Z` | 挂起到 shell，`fg` 恢复 |
| `Alt+P` | 切换模型（不清空输入） |
| `Alt+O` | 开关 fast mode |
| `?`（空输入时） | 显示快捷键帮助 |

**多行输入**：`\` + `Enter` 在任何终端都能用；`Ctrl+J` 也可以。`Shift+Enter` 只在部分终端原生支持，其他终端可以运行 `/terminal-setup` 配置。

**文本编辑**：支持 readline 风格的 `Ctrl+A/E/K/U/W/Y`、`Alt+B/F/D`。在 `/config` → Editor mode 中可以开启 vim 模式。

## 输入前缀

| 前缀 | 作用 |
| --- | --- |
| `/` | 斜杠命令或 Skill，也可以在句子中间补全，如 `跑完测试后 /com` + `Tab` |
| `!` | **Shell 模式**：直接执行命令，输出进入上下文，Claude 会自动解读（例如 `! npm test`） |
| `@` | 引用文件路径（自动补全），也可以 `@` 某个子代理 |

## 排队消息

Claude 干活时，直接输入并按 `Enter` 会**排队**，不会打断当前回合：

- 普通消息会在当前这批工具调用结束后，于同一回合内送给 Claude；
- `Ctrl+Enter`（或 `Ctrl+X Ctrl+S`）可以立即发送排队的消息；
- 在输入框第一行按 `↑`，可以把排队的消息拿回来修改。

## 后台 Bash

- 让 Claude 在后台跑命令，或者按 `Ctrl+B` 把正在运行的命令移到后台；超时的命令会自动转到后台，而不是被杀掉。
- `/tasks` 查看和管理后台任务。
- 退出 Claude Code 时，后台任务会被清理；如果用 `/bg` 把整个会话移到后台，任务会继续运行（见 [[自动化与并行]]）。

## 常用斜杠命令（精选）

**会话与上下文**

| 命令 | 作用 |
| --- | --- |
| `/clear [name]` | 开新对话（旧对话仍可 `/resume`） |
| `/compact [指令]` | 压缩上下文，可以指定摘要重点 |
| `/context` | 可视化当前上下文占用 |
| `/resume` | 切换到历史会话 |
| `/rename` | 给会话命名 |
| `/branch` | 从当前位置分叉出一个对话分支 |
| `/rewind` | 回滚代码和/或对话（别名 `/undo`） |
| `/btw <问题>` | 问一个旁支问题，**不进入对话历史** |
| `/recap` | 一句话总结当前会话 |
| `/export` | 导出对话为纯文本 |
| `/copy [N]` | 复制最近第 N 条回复 |
| `/diff` | 查看工作区改动 |

**模型与模式**

| 命令 | 作用 |
| --- | --- |
| `/model` | 切换模型（会保存为默认） |
| `/effort` | 调整推理强度 low～max |
| `/fast` | 开关 fast mode |
| `/plan [任务]` | 直接进入 plan mode |
| `/permissions` | 管理 allow/ask/deny 规则 |
| `/sandbox` | 开关沙箱 |
| `/output-style` | 切换输出风格 |

**配置与诊断**

| 命令 | 作用 |
| --- | --- |
| `/config` | 设置界面，也可以 `/config key=value` |
| `/memory` | 编辑 CLAUDE.md、开关 auto memory |
| `/init` | 生成项目 CLAUDE.md |
| `/doctor` | 检查安装和配置问题；`/doctor prompt-audit` 审查指令文件 |
| `/mcp` | 管理 MCP 连接 |
| `/hooks` | 查看 hook 配置 |
| `/skills` | 列出技能，按 `t` 按 token 排序 |
| `/statusline` | 配置状态栏 |
| `/usage` | 查看费用、额度和用量 |
| `/insights` | 生成最近会话的使用分析报告 |
| `/powerup` | 交互式功能教程 |

**内置技能（直接能用）**

| 命令 | 作用 |
| --- | --- |
| `/code-review` | 审查当前 diff 的正确性问题，`--fix` 直接修 |
| `/simplify` | 对改动做复用、简化、效率方面的清理 |
| `/security-review` | 审查当前分支的安全问题 |
| `/batch <指令>` | 把大规模改动拆给 5～30 个子代理并行做（每个在独立 worktree） |
| `/debug` | 打开调试日志，排查 Claude Code 自身的问题 |
| `/loop` | 定时重复执行提示词（见 [[自动化与并行]]） |
| `/fewer-permission-prompts` | 扫描历史，生成只读命令的白名单，减少权限弹窗 |
| `/update-config` | 用自然语言改 settings.json |

**后台与远程**

| 命令 | 作用 |
| --- | --- |
| `/bg`（`/background`） | 把当前会话移到后台，释放终端 |
| `/fork` | 复制当前对话到一个新的后台会话 |
| `/goal <条件>` | 持续工作直到条件满足 |
| `/remote-control`（`/rc`） | 让当前会话可以从手机/网页接管，见 [[Remote Control 手机远程接管会话]] |
| `/mobile` | 显示手机 App 下载二维码 |
