## 六种权限模式

| 模式 | 不用问就能做的事 | 适合 |
| --- | --- | --- |
| `default`（界面上叫 **Manual**） | 只有读 | 敏感操作、不熟的代码 |
| `acceptEdits` | 读、改文件、`mkdir`/`mv`/`cp` 等常见文件命令 | 边改边审 |
| `plan` | 读 + 只读命令，**不改源码** | 改之前先调研、出方案 |
| `auto` | 所有操作，但由后台分类器模型审查，拦截高风险行为 | 长任务、减少弹窗 |
| `dontAsk` | 读 + 预先放行的工具，其余一律拒绝 | CI、脚本 |
| `bypassPermissions` | 全部 | **只在隔离的容器/VM 里用** |

- `Shift+Tab` 循环切换，或启动时用 `claude --permission-mode plan`。
- v2.1.283 起，交互式终端会话**默认就是 auto 模式**。
- 无论哪种模式，deny 规则都生效；删除关键路径的 `rm`、显式 ask 规则等永远不会被自动批准。
- `.git`、`.claude` 等受保护路径的写入，除 bypass 外都不会自动放行。

### Plan mode 的用法

1. `Shift+Tab` 切到 `⏸ plan mode on`，让它读代码、回答问题；
2. 让它出详细计划，`Ctrl+G` 可以在编辑器里直接改计划；
3. 批准计划（或 `Shift+Tab` 退出）后开始实现。

可以用模型别名 `opusplan`：plan 阶段用 Opus，执行阶段自动切到 Sonnet。

## 权限规则

用 `/permissions` 管理，或写在 settings.json 里：

```json
{
  "permissions": {
    "allow": ["Bash(npm run *)", "Bash(git commit *)"],
    "deny":  ["Bash(git push *)", "Read(./.env)"]
  }
}
```

- 判定顺序：**deny → ask → allow**，先匹配到哪条就用哪条；allow 无法在 deny 里开例外。
- 写法：`Tool` 或 `Tool(specifier)`：
  - `Bash(npm run build)`：精确匹配
  - `Bash(npm run *)`：前缀匹配。**`*` 要放在子命令后面**：`Bash(git log *)` 只放行 `git log`，`Bash(git *)` 会放行所有 git 命令
  - `Read(./.env)`、`WebFetch(domain:example.com)`
- 只写工具名（如 `Bash`）的 deny 规则，会让这个工具从 Claude 的工具列表里彻底消失。
- 权限规则由 Claude Code 程序强制执行；写在 CLAUDE.md 里的"不要做 X"只是建议。
- 权限弹窗上按 `Tab` 可以附一句评论，告诉 Claude 为什么允许或拒绝。
- 想少点弹窗：运行 `/fewer-permission-prompts`，或者开 `/sandbox`（沙箱里的命令可以免确认）。

## Settings 文件与优先级

| 文件 | 作用范围 |
| --- | --- |
| `~/.claude/settings.json` | 本机所有项目（个人） |
| `.claude/settings.json` | 当前项目，提交到 git 后团队共享 |
| `.claude/settings.local.json` | 当前项目，仅自己（会自动加到 git excludes） |
| managed settings | 组织统一下发，不能被覆盖 |

优先级从高到低：**managed > 命令行参数 > local > project > user**。列表类配置（如 permissions.allow）会**合并**而不是覆盖。

改配置的方式：`/config` 界面、`/config key=value`、直接编辑文件，或者用 `/update-config` 让 Claude 帮你改。

## 模型与推理强度

- 别名：`sonnet`（日常）、`opus`（复杂推理）、`haiku`（简单任务）、`fable`、`best`、`opusplan`，以及 1M 上下文版 `opus[1m]`。
- `/model` 切换并保存为默认；`Alt+P` 快速切换。
- `/effort low|medium|high|xhigh|max` 调推理强度；在滑块里按 `s` 表示只对本次会话生效。Opus 5.5 / Sonnet 5.5 默认 `medium`，`max` 只对当前会话生效。
- `/fast` 开关 fast mode（同一个模型，输出更快）。
