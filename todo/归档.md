# 归档

> 更新时间：2026-09-28
> 定位：存放**已不再参考 / 不再采纳**的方案与决策痕迹，供回溯"为什么没走这条路"，避免日后重新评估时走弯路。

## 与 todo 清单的协作关系

- **入口**：`todo/待办清单.md` 的「搁置」区是迁移来源
- **迁移时机**：方案确认不采纳 / 决定长期搁置 / 已被替代方案取代时，从 todo 清单移到此处
- **回写原则**：归档区是**只追加、不删改**的历史记录；不要把还在犹豫的方案提前归档
- **再启用**：如某条目重新评估后决定再做，从归档区移除并写回 todo 清单对应区块

## 条目格式

每条记录包含：

- **标题**：方案名
- **不采纳日期**：YYYY-MM-DD
- **不采纳原因**：一句话说清决策点
- **替代方案**（如有）：当前走了哪条路
- **原资料链接**（如有）：仓库 / 文档 / 相关笔记
