RAID（Redundant Array of Independent Disks，独立冗余磁盘阵列）通过将多块硬盘组合使用，实现性能提升和/或数据冗余。核心思想是把数据切割后分散存放在多块盘上，利用分散读写提升性能，利用副本或校验信息保障安全。

---

## 常见 RAID 级别对比

||RAID 0|RAID 1|RAID 5|RAID 6|RAID 10|
|---|---|---|---|---|---|
|最少硬盘数|2|2|3|4|4|
|可用容量|n|1（最小盘）|n-1|n-2|n/2|
|读性能|高|中高|高|高|高|
|写性能|高|中（需写多份）|中（需算校验）|较低（双校验）|高|
|允许坏盘数|0|n-1|1|2|每镜像组各 1 块|
|典型场景|临时数据/缓存|系统盘/引导盘|NAS/文件服务器|大容量存储|数据库/生产环境|

> n = 硬盘总数，所有盘容量相同时成立。混用不同容量的盘时，以最小盘为准。

---

## RAID 0 — 条带化（Striping）

- 数据被切成块（block），依次轮流写入各盘
- 所有盘并行读写，吞吐量约为单盘的 n 倍
- **无任何冗余**，任意一块盘损坏，整个阵列数据全部丢失
- 适用于对性能要求高、数据可丢弃的场景（如缓存、swap、视频剪辑临时盘）

## RAID 1 — 镜像（Mirroring）

- 每块盘存储完全相同的数据副本
- 可用容量 = 1 块盘（n 块盘利用率 1/n）
- 读取时控制器可从多块盘并行读，有一定读性能提升；写入需要写所有副本，略慢
- 只要还剩一块盘就能正常工作，冗余性最高
- 适用于系统盘、引导盘等容量小但安全性要求高的场景
- **生产环境用得很多**，不是"没用的模式"

## RAID 5 — 分布式奇偶校验

- 数据和校验信息（Parity）分散存储在所有盘上
- 校验原理是**异或运算**（XOR）：A ⊕ B = P，已知任意两个可推出第三个
- 与 RAID 3 的区别：RAID 3 把所有校验集中存在一块盘上（校验盘容易成为瓶颈和故障点），RAID 5 将校验块轮流分布到每块盘
- 可用容量 = (n-1) 块盘，利用率随盘数增加而提高
- 允许坏 1 块盘，坏盘后通过其余盘的数据 + 校验重建
- **重建风险**：盘越大，重建耗时越长，重建期间再坏一块就全完了（URE 风险）

## RAID 6 — 双重校验

- RAID 5 的增强版，使用两种独立的校验算法（P + Q）
- 允许同时坏 2 块盘
- 可用容量 = (n-2) 块盘，写性能比 RAID 5 更低（每次写要算两份校验）
- 大容量盘（4TB+）场景下比 RAID 5 更安全，逐渐成为主流选择

## RAID 10 — 先镜像再条带

- 先将硬盘两两做 RAID 1（镜像），再将多组 RAID 1 做 RAID 0（条带）
- 兼具 RAID 0 的高性能和 RAID 1 的高安全性
- 可用容量 = n/2
- 每个镜像组内允许坏 1 块盘；**"最多坏 50%"的前提是坏的盘分布在不同镜像组**，同一组两块全坏则数据丢失
- 适用于数据库、生产业务等对性能和安全都有要求的场景

### RAID 10 vs RAID 01

||RAID 10|RAID 01|
|---|---|---|
|结构|底层 RAID 1 → 上层 RAID 0|底层 RAID 0 → 上层 RAID 1|
|扩展性|好，可添加新的镜像组|差，新增的只是镜像副本|
|容错|每组可坏 1 盘，组间互不影响|底层 RAID 0 坏 1 盘整组崩溃|
|结论|生产首选|几乎无人使用|

---

## 选型指南

- **数据可丢、追求极致速度** → RAID 0
- **系统盘 / 引导盘，容量不大但不能丢** → RAID 1
- **大容量文件存储、成本敏感** → RAID 5（盘 ≤ 2TB）或 RAID 6（盘 > 2TB）
- **数据库 / 核心业务，性能和安全都要** → RAID 10
- **Homelab / NAS** → 优先考虑 ZFS（mirror / raidz），思路与传统 RAID 一致但多了数据校验和自修复

## Linux 软 RAID 管理（mdadm）

mdadm（Multiple Devices Admin）是 Linux 下管理软件 RAID 的工具。

### 常用参数

|参数|功能|
|---|---|
|`-C`|创建阵列|
|`-v`|显示过程|
|`-n`|指定阵列中的设备数量|
|`-l`|指定 RAID 级别|
|`-x`|指定备用盘数量|
|`-D`|查看阵列详细信息|
|`-Q`|查看阵列摘要|
|`-S`|停止阵列|
|`-a`|添加设备到阵列|
|`-f`|标记设备为故障|
|`-r`|从阵列移除设备|

### 创建 RAID 10

```bash
# 用 4 块盘创建 RAID 10
mdadm -Cv /dev/md0 -n 4 -l 10 /dev/sdb /dev/sdc /dev/sdd /dev/sde

# 查看阵列状态
mdadm -D /dev/md0

# 格式化
mkfs.ext4 /dev/md0

# 挂载
mkdir -p /raid
mount /dev/md0 /raid

# 写入 fstab 实现开机自动挂载
echo '/dev/md0  /raid  ext4  defaults  0 0' >> /etc/fstab
```

### 创建带备用盘的 RAID 5

```bash
# 3 块数据盘 + 1 块热备盘
mdadm -Cv /dev/md0 -n 3 -l 5 -x 1 /dev/sdb /dev/sdc /dev/sdd /dev/sde
```

备用盘（Spare）平时闲置，某块盘故障时自动顶替并开始重建，无需手动干预。

### 磁盘故障处理

```bash
# 1. 标记故障盘
mdadm /dev/md0 -f /dev/sdb

# 2. 移除故障盘
mdadm /dev/md0 -r /dev/sdb

# 3. 添加新盘（自动开始重建）
mdadm /dev/md0 -a /dev/sdf

# 4. 查看重建进度
mdadm -D /dev/md0
```

阵列降级状态会显示 `degraded`，新盘重建中显示 `recovering`。

### 删除 RAID

```bash
# 1. 删除 /etc/fstab 中对应的挂载条目
# 2. 取消挂载
umount /dev/md0
# 3. 停止阵列
mdadm -S /dev/md0
# 4. 关机拔盘（如需要）
```
