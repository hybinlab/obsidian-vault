## /etc/fstab 格式

```
设备标识    挂载点    文件系统类型    挂载选项    dump备份    fsck检查
```

示例：

```
UUID=xxxx-xxxx          /mnt/data    ext4     defaults,nofail  0  2
/dev/disk/by-id/dm-xxx  /            ext4     defaults         0  1
/swap.img               none         swap     sw               0  0
```

### 各字段说明

| 字段     | 说明                                              |
| ------ | ----------------------------------------------- |
| 设备标识   | 推荐用 UUID（`blkid` 查看），避免设备名漂移                    |
| 挂载点    | 挂载到的目录，需提前创建                                    |
| 文件系统类型 | ext4、xfs、ntfs-3g、swap 等                         |
| 挂载选项   | `defaults` 即 rw,suid,dev,exec,auto,nouser,async |
| dump备份 | 0 = 不备份（现在基本都写 0）                               |
| fsck检查 | 0 = 不检查，1 = 根分区优先，2 = 其他分区之后检查                  |

### 常用挂载选项

|选项|说明|
|---|---|
|`defaults`|默认选项集合|
|`nofail`|设备不存在时不阻塞开机（外接盘、可选盘必加）|
|`noatime`|不更新访问时间，减少写入，SSD 友好|
|`ro`|只读挂载|
|`noexec`|禁止执行文件（安全加固用）|

### 注意事项

- `/dev/sdX` 设备名由内核识别顺序决定，不是物理插槽顺序，重启可能变
- 分区编号不一定连续，`sda3` 不代表有 3 个分区
- NTFS 盘的 fsck 字段写 `0 0`，Linux fsck 不处理 NTFS
- 修改 fstab 后用 `mount -a` 测试，避免重启后挂载失败进不了系统

## 常用命令

```bash
# 查看所有块设备
lsblk

# 查看设备 UUID
blkid

# 查看磁盘使用情况
df -h

# 手动挂载
mount /dev/sdb1 /mnt/data

# 挂载 fstab 中所有未挂载的条目（测试用）
mount -a

# 卸载
umount /mnt/data
```

## 设备命名

|前缀|类型|
|---|---|
|`/dev/sd[a-z]`|SATA / SAS / USB 磁盘|
|`/dev/vd[a-z]`|virtio 虚拟磁盘（VM 里常见）|
|`/dev/nvme0n1`|NVMe SSD|
|`/dev/sr0`|虚拟光驱 / CD-ROM|

## 文件系统对比

|文件系统|特点|
|---|---|
|ext4|最普及，稳定成熟，大多数场景首选|
|XFS|高性能日志文件系统，RHEL 7/8 默认|
|ZFS|快照 + 校验 + RAID 一体化，PVE 原生支持|
|Btrfs|Linux 原生，支持快照和压缩|

### RAID 方案选择

- **mdadm + ext4**：传统方案，稳定可靠，但无数据校验
- **ZFS (RAIDZ)**：RAID + 文件系统一体，自动校验和修复静默损坏，适合在意数据完整性的场景

## 权限速查

### 常用数字权限

|权限|用途|
|---|---|
|`755`|标准目录 / 可执行文件|
|`700`|私有目录（如 `~/.ssh`）|
|`644`|标准文件（配置文件）|
|`600`|敏感文件（密钥、私钥）|
|`400`|只读密钥文件（如 AWS pem）|

### 目录权限含义（与文件不同）

|权限|文件|目录|
|---|---|---|
|r|读取内容|列出目录内容（ls）|
|w|修改内容|创建 / 删除 / 重命名文件|
|x|执行|进入目录（cd），访问文件的前提|

### 特殊权限

|标志|名称|作用|
|---|---|---|
|`s`（属主位）|SUID|执行时临时获得文件属主权限（如 passwd）|
|`s`（属组位）|SGID|执行时获得属组权限 / 目录下新文件继承组|
|`t`|Sticky Bit|目录下只能删自己的文件（如 /tmp）|

### ls -l 第一个字符（文件类型）

|字符|类型|
|---|---|
|`-`|普通文件|
|`d`|目录|
|`l`|软链接|
|`b`|块设备|
|`c`|字符设备|
|`p`|管道|
|`s`|socket|

## 重定向速查

```bash
命令 > 文件          # stdout 覆盖写入
命令 >> 文件         # stdout 追加写入
命令 2> 文件         # stderr 覆盖写入
命令 2>> 文件        # stderr 追加写入
命令 >> 文件 2>&1    # stdout + stderr 追加写入（推荐，POSIX 兼容）
命令 &>> 文件        # 同上（Bash 4+ 语法糖）
```

- `2>&1` 中的 `&` 表示后面是文件描述符，不是文件名
- 文件描述符：0 = stdin，1 = stdout，2 = stderr
