## 格式对比

| 格式         | 工具          | 打包  | 压缩  | 跨平台   | 压缩率 | 速度  |
| ---------- | ----------- | --- | --- | ----- | --- | --- |
| `.tar`     | tar         | ✅   | ❌   | Linux | 无   | 最快  |
| `.tar.gz`  | tar + gzip  | ✅   | ✅   | Linux | 中   | 快   |
| `.tar.bz2` | tar + bzip2 | ✅   | ✅   | Linux | 高   | 慢   |
| `.tar.xz`  | tar + xz    | ✅   | ✅   | Linux | 最高  | 最慢  |
| `.gz`      | gzip        | ❌   | ✅   | Linux | 中   | 快   |
| `.zip`     | zip/unzip   | ✅   | ✅   | 全平台   | 中   | 快   |

**选择原则**：

- 纯Linux环境 → `tar.gz`
- 跨平台给Windows用 → `zip`
- 备份大文件不在乎时间 → `tar.xz`

## tar

### 核心参数

|参数|说明|
|---|---|
|`-c`|create，创建归档|
|`-x`|extract，解压|
|`-z`|使用gzip压缩（.tar.gz）|
|`-j`|使用bzip2压缩（.tar.bz2）|
|`-J`|使用xz压缩（.tar.xz）|
|`-f`|指定文件名（必须放最后）|
|`-v`|显示处理过程|
|`-C`|指定解压目标目录|
|`-t`|列出归档内容，不解压|

### 常用命令

```bash
# 打包并压缩（最常用）
tar -czf archive.tar.gz /path/to/dir

# 解压到当前目录
tar -xzf archive.tar.gz

# 解压到指定目录
tar -xzf archive.tar.gz -C /target/dir

# 查看归档内容（不解压）
tar -tzf archive.tar.gz

# 打包时显示进度
tar -czvf archive.tar.gz /path/to/dir

# bzip2压缩（压缩率更高）
tar -cjf archive.tar.bz2 /path/to/dir
tar -xjf archive.tar.bz2

# xz压缩（压缩率最高）
tar -cJf archive.tar.xz /path/to/dir
tar -xJf archive.tar.xz

# 排除某个目录
tar -czf archive.tar.gz /path/to/dir --exclude=/path/to/dir/logs
```

### 记忆口诀

```
压缩：tar -czf 目标.tar.gz 源
解压：tar -xzf 文件.tar.gz

c=create  x=extract  z=gzip  f=file
```

## gzip / gunzip

只压缩单个文件，压缩后原文件默认被删除。

```bash
# 压缩文件（原文件被删除）
gzip file.txt         # 生成 file.txt.gz

# 压缩并保留原文件
gzip -k file.txt

# 解压
gunzip file.txt.gz
gzip -d file.txt.gz   # 等价

# 查看压缩率
gzip -v file.txt

# 指定压缩级别（1最快，9最小）
gzip -9 file.txt
```

## zip / unzip

打包+压缩一体，跨平台首选。

```bash
# 压缩目录（-r递归）
zip -r archive.zip /path/to/dir

# 压缩多个文件
zip archive.zip file1.txt file2.txt

# 解压到当前目录
unzip archive.zip

# 解压到指定目录
unzip archive.zip -d /target/dir

# 查看zip内容（不解压）
unzip -l archive.zip

# 压缩时排除某类文件
zip -r archive.zip /path/to/dir --exclude "*.log"

# 加密压缩
zip -e archive.zip file.txt
```

## 高频场景

```bash
# 备份目录
tar -czf backup_$(date +%Y%m%d).tar.gz /data/

# 解压不知道格式的文件（根据扩展名判断）
# .tar.gz 或 .tgz
tar -xzf file.tar.gz

# .tar.bz2
tar -xjf file.tar.bz2

# .tar.xz
tar -xJf file.tar.xz

# .zip
unzip file.zip

# .gz（单文件）
gunzip file.gz

# 打包后立即查看大小
tar -czf archive.tar.gz /path/ && ls -lh archive.tar.gz

# 远程传输时边打包边传（不落盘）
tar -czf - /path/to/dir | ssh user@remote "cat > /remote/archive.tar.gz"
```
