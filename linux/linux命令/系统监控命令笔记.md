## top

实时动态显示系统资源使用情况。

```bash
top              # 启动top
top -u root      # 只看指定用户的进程
top -p 1234      # 只监控指定PID
```

### top界面交互快捷键

|按键|说明|
|---|---|
|`q`|退出|
|`M`|按内存排序|
|`P`|按CPU排序|
|`T`|按运行时间排序|
|`k`|输入PID杀进程|
|`1`|展开显示每个CPU核心|
|`h`|帮助|

### top输出说明

```
top - 21:30:00 up 2 days,  3:20,  2 users,  load average: 0.52, 0.48, 0.45
Tasks: 180 total,   1 running, 179 sleeping,   0 stopped,   0 zombie
%Cpu(s):  2.3 us,  0.5 sy,  0.0 ni, 96.8 id,  0.3 wa,  0.0 hi,  0.1 si
MiB Mem :  15894.6 total,   8234.2 free,   4321.1 used,   3339.3 buff/cache
MiB Swap:   4096.0 total,   4096.0 free,      0.0 used.  10234.5 avail Mem
```

- `load average`：1/5/15分钟平均负载，超过CPU核心数说明过载
- `us`：用户态CPU占用
- `sy`：内核态CPU占用
- `id`：CPU空闲率
- `wa`：等待IO的CPU时间，过高说明磁盘或网络IO有瓶颈
- `buff/cache`：缓存，内存不够时会自动释放

## htop

top的增强版，界面更友好，支持鼠标操作，推荐替代top。

```bash
# 安装
apt install htop     # Debian/Ubuntu
pacman -S htop       # Arch

htop
htop -u root         # 只看指定用户
```

### htop快捷键

|按键|说明|
|---|---|
|`F2`|设置|
|`F3`|搜索进程|
|`F4`|过滤进程|
|`F5`|树状显示|
|`F6`|排序方式|
|`F9`|杀进程|
|`F10`|退出|

## df

查看磁盘空间使用情况。

```bash
df -h              # 人类可读格式（GB/MB）
df -h /            # 只看根分区
df -T              # 显示文件系统类型
df -i              # 查看inode使用情况
```

**inode耗尽**也会导致"磁盘满"，即使空间还有剩余：

```bash
df -i    # 查看inode使用率，Use%接近100%就要处理
```

## du

查看目录/文件占用空间。

```bash
du -sh /var/log          # 查看目录总大小
du -sh /*                # 查看根目录下各目录大小
du -h --max-depth=1 /    # 只看一层深度

# 找出最大的目录/文件
du -sh /var/* | sort -rh | head -10
```

**df vs du**：

- `df`看整个分区的使用情况
- `du`看具体目录或文件占了多少

## free

查看内存使用情况。

```bash
free -h              # 人类可读格式
free -h -s 2         # 每2秒刷新一次
```

```
              total        used        free      shared  buff/cache   available
Mem:           15Gi        4.2Gi       8.1Gi      1.2Mi       3.1Gi        10Gi
Swap:         4.0Gi          0B       4.0Gi
```

- `available`才是真正可用内存，不是`free`
- `buff/cache`是系统缓存，内存不足时会自动释放
- Swap有使用说明内存压力较大

## uptime

查看系统运行时间和负载。

```bash
uptime
# 21:30:00 up 2 days,  3:20,  2 users,  load average: 0.52, 0.48, 0.45
```

- `up 2 days 3:20`：系统已运行时长
- `load average`：1/5/15分钟平均负载
- 负载值超过CPU核心数说明系统过载

## lsof

列出打开的文件（包括网络连接、设备等）。

```bash
lsof -i :8080          # 查看占用8080端口的进程
lsof -p 1234           # 查看指定进程打开的文件
lsof -u root           # 查看root用户打开的文件
lsof /var/log/app.log  # 查看谁在使用这个文件
```

**常用场景**：删除文件后磁盘空间没释放，说明还有进程持有该文件句柄：

```bash
lsof | grep deleted    # 找出已删除但未释放的文件
```

## watch

定时重复执行命令，实时监控。

```bash
watch -n 2 df -h              # 每2秒刷新一次磁盘使用
watch -n 1 "ps aux | grep nginx"
watch -d free -h              # -d高亮显示变化的部分
```

## 高频组合场景

```bash
# 排查磁盘占满
df -h                                    # 先定位哪个分区满了
du -sh /var/* | sort -rh | head -10     # 找最大的目录
lsof | grep deleted                      # 找已删除未释放的文件

# 排查内存压力
free -h                                  # 查看内存使用
ps aux --sort=-%mem | head -10          # 找最耗内存的进程

# 排查CPU高
top                                      # 实时看
ps aux --sort=-%cpu | head -10          # 找最耗CPU的进程

# 排查IO瓶颈
top                                      # 看wa（IO等待）是否偏高
iostat -x 1                             # 详细IO统计（需装sysstat）

# 快速系统概览
uptime && free -h && df -h
```
