## 常用命令

```bash
ps aux          # 查看所有进程（BSD风格）
ps -ef          # 查看所有进程（UNIX风格）
ps aux | grep nginx   # 过滤特定进程
ps -p 1234      # 查看指定PID的进程
ps --forest     # 树状显示进程父子关系
```

## 输出字段说明

|字段|说明|
|---|---|
|USER|进程所有者|
|PID|进程ID|
|%CPU|CPU占用率|
|%MEM|内存占用率|
|VSZ|虚拟内存使用量（KB）|
|RSS|物理内存占用量（KB）|
|TTY|所在终端（`?`表示非终端进程）|
|STAT|进程状态|
|START|进程启动时间|
|TIME|实际占用CPU的累计时间|
|COMMAND|命令名称与参数|

## 进程状态（STAT字段）

### 五种基本状态

|状态|含义|
|---|---|
|R（运行）|正在运行或在运行队列中等待|
|S（中断）|休眠中，等待某个条件或信号|
|D（不可中断）|等待IO，`kill -9`也杀不掉，通常是在等待磁盘或网络IO响应|
|Z（僵尸）|进程已终止，但父进程未调用wait()回收，描述符仍存在|
|T（停止）|收到停止信号后暂停运行|

### 补充修饰符

|修饰符|含义|
|---|---|
|`<`|高优先级进程|
|`N`|低优先级进程|
|`L`|有页面被锁定在内存中|
|`s`|包含子进程（session leader）|
|`l`|多线程进程|
|`+`|位于前台进程组|

例如`Ss`表示该进程是session leader且处于睡眠状态，`Sl`表示多线程睡眠进程。

## 重点状态说明

### D 状态（不可中断睡眠）

```bash
ps aux | grep " D "
```

- 进程在等待IO完成，通常是磁盘读写或NFS挂载
- `kill -9`无效，必须等IO完成或重启
- 大量D状态进程 → 排查磁盘性能或网络存储问题

### Z 状态（僵尸进程）

```bash
ps aux | grep " Z "
```

- 子进程已死，父进程未回收
- 不占CPU和内存，只占PID
- 大量僵尸进程 → 父进程代码有问题，未正确处理SIGCHLD信号
- 处理方式：kill掉父进程，僵尸子进程会被init(PID 1)自动回收

## 实用组合

```bash
# 按CPU排序，取前10
ps aux --sort=-%cpu | head -10

# 按内存排序，取前10
ps aux --sort=-%mem | head -10

# 查看某进程的线程
ps -T -p <PID>

# 查看进程树
ps auxf

# 只显示当前用户进程
ps -u $USER
```

## ps vs top

||ps|top|
|---|---|---|
|输出方式|快照（一次性）|实时刷新|
|适合场景|脚本处理、精确查找|实时监控、交互操作|
|过滤|配合grep|内置过滤|
